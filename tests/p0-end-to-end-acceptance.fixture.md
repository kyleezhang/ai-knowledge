# Agent Memory Boundary

Agent memory can improve AI learning workflows, but raw material, discussion-stage understanding, and approved knowledge must remain separate.

## Why the boundary matters

If a system answers directly from raw material or unconfirmed discussion, it can overstate certainty and blur the line between evidence and confirmed knowledge.

## Practical rule

Only approved Notes should be indexed and used for grounded answers in the P0 workflow.

## What good approval looks like

A discussion can become approved knowledge only after the user explicitly confirms the discussion is ready, the system creates a draft Note, QA passes, and the Note is approved.
