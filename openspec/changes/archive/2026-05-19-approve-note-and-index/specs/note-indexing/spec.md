## MODIFIED Requirements

### Requirement: Only Approved Notes Enter Main Index
The system SHALL create main index entries only for notes with status `approved`. P0 `note index` MUST reject draft, archived, and superseded Notes.

#### Scenario: Approved note is indexed
- **WHEN** a `Note` has status `approved`
- **THEN** the system may build a main index entry for it

#### Scenario: Draft note is indexed
- **WHEN** a `Note` has status `draft`
- **THEN** the system rejects main indexing
- **AND** no main index entry is created

#### Scenario: Archived or superseded note is indexed
- **WHEN** a `Note` has status `archived` or `superseded`
- **THEN** the system rejects main indexing
- **AND** preserves the note without treating it as current knowledge

### Requirement: Index Entry References Note
The system SHALL include enough metadata in each index entry to trace back to the note. P0 index entries MUST include `note_id`, `title`, `summary`, `keywords`, `tags`, `status = approved`, `approved_at`, `related_note_ids`, and `vector_ref = null`.

#### Scenario: Index entry is created
- **WHEN** a note is indexed
- **THEN** the entry includes `note_id`, title or summary metadata, tags or keywords when available, and the path or reference needed to load the note

#### Scenario: P0 index entry is created
- **WHEN** `ai-knowledge note index <note_id>` succeeds for an approved Note
- **THEN** the index entry status is `approved`
- **AND** `vector_ref` is `null`

### Requirement: Indexing Uses Storage Helpers
The system SHALL resolve index paths through storage path helpers.

#### Scenario: Index file is written
- **WHEN** an index entry is persisted
- **THEN** the path is generated by storage helpers
- **AND** workflows do not hand-build knowledge paths

#### Scenario: P0 index file path is generated
- **WHEN** an approved Note is indexed
- **THEN** the index file is written under `knowledge/index/YYYY/MM/note_xxx.index.json`

## ADDED Requirements

### Requirement: Note Index CLI Supports JSON Output
The system SHALL support machine-readable output for Note indexing.

#### Scenario: User requests JSON output for note index
- **WHEN** the user runs `ai-knowledge note index <note_id> --json`
- **THEN** the CLI returns the index workflow result as JSON
- **AND** includes the generated index entry
